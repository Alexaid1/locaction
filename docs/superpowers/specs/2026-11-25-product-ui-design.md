# LOCACTION - интерфейс продукта (часть 4 ИКР)

Дата: 25.11.2026. Статус: на согласовании.
Основа: [дизайн ИКР](../../../../LOCACTION_ИКР_дизайн.md) (разделы 2, 3, 6.5), [контракт](../../../contract/README.md).

## Зачем

Владелец стрит-ритейла должен за пару минут получить карточку по любой точке Москвы: оценка места, прогноз на год (если модель подтверждена), потоки людей. Интерфейс делается сейчас, параллельно с данными и моделью, на заглушке API. Когда появится сервер, интерфейс переключается заменой одного адреса в `config.mjs`.

Решения владельца 25.11.2026: карта раскрывается на весь экран; минимум текста, больше визуальной навигации; красивые, но не перегружающие анимации; после расчёта - «игровой» 3D-вид с влиянием объектов вокруг и «дымом» потоков; визуализация бесплатная, что будет платным - решим позже; визуализация на MapLibre со своим слоем частиц; реальные высоты зданий - после сбора данных.

## Цели, не-цели, анти-цели

**Цели:** ввод любой точки (клик или адрес); анкета плитками или свободный текст; карточка по контракту `locaction.card/1`; 3D-вид результата; работа на GitHub Pages без ключей и сервера; переключение на настоящий API одной строкой.

**Не-цели сейчас:** настоящая оплата; настоящая LLM (заглушка разбирает текст правилами); реальные высоты зданий; аккаунты и история отчётов на сервере.

**Анти-цели:** текст стеной вместо визуала; анимации, которые мешают или тормозят на ноутбуке; потоки, похожие на замер; процент прогноза без подтверждённой модели; объекты 2ГИС на карте.

## Путь пользователя

```
[Главная: заголовок, поиск, карта в рамке]
   | кнопка «Развернуть» / первое касание карты / ввод адреса
[Карта на весь экран] - поиск с подсказками, клик по зданию
   | здание подсвечивается и «вырастает», камера подлетает
[Мини-карточка здания: адрес, тип, до метро, площадь] -- «Подтвердить»
   | карта уходит в фон (затемняется, отъезжает)
[Анкета: плитки категорий -> формат, чек, часы, аудитория | вкладка «Своими словами»]
   | «Рассчитать»
[Расчёт: от точки расходится кольцо 800 м, камера наклоняется]
   |
[Результат: 3D-карта на весь экран + панель карточки]
   объекты влияния всплывают по очереди, линии к точке (зелёные - помогают, красные - мешают)
   «дым» потоков по улицам, переключатель утро / день / вечер
   панель: кольцо оценки, прогноз (2 состояния), потоки, показатели иконками
   кнопки: «Разбор от ИИ», «К сравнению», «Сохранить PDF», «Новая точка»
```

Состояние (точка, параметры, экран) пишется в адрес страницы после `#`, ссылкой можно поделиться и вернуться.

## Экраны

1. **Главная.** Короткий заголовок, строка поиска, карта в рамке. Под поиском ссылка «Пример: 3 адреса в Митино» ведёт на нынешний сравнительный отчёт (переезжает в `example.html`).
2. **Карта на весь экран.** Раскрытие - анимация рамки до размеров окна (0,5 с). Сверху поиск, справа масштаб, кнопка «Свернуть». Подсказки адресов - из своего индекса адресов OSM по зданиям, без внешнего геокодера; выбор подсказки перелетает к зданию. Клик вне здания ставит метку «Точка на карте» с названием ближайшей улицы.
3. **Мини-карточка здания.** Иконки и короткие значения: тип здания, ≈ м до ближайшей станции метро, площадь контура. Кнопки «Подтвердить» и «×».
4. **Анкета.** Шаг 1 - группа (Еда, Магазин, Услуги) и плитка категории с иконкой, 28 категорий. Шаг 2 - формат чипами, средний чек ползунком, часы двойным ползунком и чипами дней, аудитория чипами с иконками. Вкладка «Своими словами»: поле текста, «Разобрать», затем «Мы поняли так» - параметры чипами, не указанные жёлтые, любой можно поправить. Внизу «Рассчитать».
5. **Результат.** Камера наклоняется до 55°, медленно облетает точку, пока пользователь не тронет карту. Здания объёмные (условная высота по типу, выбранное выше и светится), кольцо радиуса 800 м. Объекты влияния - иконки с подъёмом по очереди; от каждого к точке линия с бегущим светом, толщина - сила влияния. Потоки - светлые частицы со шлейфом вдоль улиц, густота по интенсивности, переключатель периода плавно перестраивает потоки. Подпись «иллюстрация, не замер» не убирается. Панель (справа на компьютере, выдвижная снизу на телефоне): кольцо оценки с отсчётом, блок прогноза, полоски потоков, показатели строками «иконка, значение, полоска процентиля». Наведение на показатель подсвечивает его объекты на карте.
6. **Разбор от ИИ.** Кнопка без цены (`price_rub = null`). Заглушка собирает разбор шаблоном из чисел карточки. Пункты разбора подсвечивают свои показатели на карте.
7. **Сравнение.** «К сравнению» собирает до 5 карточек (в памяти браузера). Экран сравнения - карточки рядом: оценка, прогноз, главные показатели.

Анимации 0,3-0,8 с, плавные кривые. При «уменьшить движение» в системе камера не облетает, частицы стоят (статичные линии потоков), появления без движения. Если нет WebGL - главная показывает картинку Митино и даёт ввести адрес; карточка открывается без 3D.

## Подходы к визуализации

| Подход | Плюсы | Минусы |
|---|---|---|
| **A. MapLibre + свой слой частиц (выбран владельцем)** | Без новых библиотек, 3D зданий и наклон уже есть в MapLibre, вид «дыма» полностью свой | Эффекты пишем сами |
| B. deck.gl поверх MapLibre | Готовые слои следов и дуг | ~1 МБ кода, стандартный вид |
| C. Three.js поверх карты | Максимум эффектов | Тяжело для слабых устройств, перегруз |

## Временный расчёт на заглушке

`config.mjs`: `API_BASE = 'stub'`. Заглушка реализует те же три запроса, что и сервер, и отдаёт JSON строго по контракту.

- **Карточка.** Объекты OSM в радиусе 800 м из своего слоя `map/poi/` (тот же снимок OSM, что у подложки; собирает `tools/build_poi.py`). Сначала план был брать их из бесплатного Overpass, но 25.11.2026 все четыре публичных сервера Overpass были перегружены, а свой слой ещё и не отправляет координаты пользователя на чужие серверы. По объектам считается демо-индекс v2, обобщённый на категорию: конкуренты своей категории 300 м, метро, остановки 300 м, офисы 500 м, якоря 300 м. Объекты идут в `map.points`. `engine.kind = demo_index_v2`, процентили `null`, `forecast.status = not_validated`. Если слой не загрузился за 12 с - примерные данные, `engine.kind = stub`, на экране плашка «Примерные данные».
- **Потоки.** `status = illustration`: отрезки улиц из подложки (`roads`) в радиусе точки, интенсивность по типу улицы и близости к метро и якорям, разная для утра, дня и вечера. Числа `null`, полоски относительные.
- **Разбор текста** - правила по ключевым словам (категория, формат, чек, часы, аудитория).
- **Разбор от ИИ** - шаблон из чисел карточки, проходит ту же проверку чисел.
- `?forecast=validated` в адресе показывает состояние с подтверждённым прогнозом на примерных числах, с плашкой «Пример состояния» - для показа дизайна.

## Ограничения

- GitHub Pages, статические файлы, без сборщика; MapLibre и PMTiles уже лежат в `map/vendor`.
- Публикация на GitHub Pages и траты на LLM - только с явного согласия владельца.
- Клиент не видит данных 2ГИС; в заглушке только OSM.
- Стиль текстов - дефис вместо тире.

## Оставлено исполнителю

Иконки (свои SVG в стиле демо), точные кривые анимаций, таблица соответствия категорий тегам OSM для конкурентов, формула интенсивности потоков в заглушке, нарезка индекса адресов на части, раскладка на телефоне.
