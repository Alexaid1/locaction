# Источники карты LOCACTION

## Публичные данные

`osm-basemap.pmtiles` и `buildings.pmtiles` построены из [московского PBF OpenStreetMap](https://download.openstreetmap.fr/extracts/russia/central_federal_district/). Срез поставщика от 23.11.2026. SHA-256 файла: `DC77F35912910113B12DCCEC12804BDBFC5F9D39AC37630683C510BCF337A465`.

Публичные векторные архивы распространяются на условиях [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Авторство — [© участники OpenStreetMap](https://www.openstreetmap.org/copyright). Скрипт пересборки и ссылка на исходную выгрузку приведены в [README](../README.md). Карта сохраняет оформление LOCACTION. Границы и дороги публичной подложки тоже взяты из OSM, чтобы оба архива имели подтверждённый источник.

Границу экспорта задаёт административный контур Москвы в OSM, в том числе ТиНАО и Зеленоград. При подготовке слоя отобрано 289 658 контуров. По внутренней точке 289 614 контуров сопоставились с 12 округами из `ao.geojson`, 44 не сопоставились из-за различий границ. Геометрия и атрибуты `ao.geojson` в публичные файлы не входят. Векторные тайлы зданий загружаются при приближении от z14. Слой содержит полигоны зданий, включая составные контуры и внутренние кольца. Площадь контура рассчитана в EPSG:32637 до разбивки на тайлы и округлена до м².

## Адреса, типы и площади

- Публичные адреса взяты из тегов `addr:*` самих контуров OSM. Для трёх демо-точек адреса и УНОМ сверены отдельно по локальной копии адресного реестра Москвы, набор 60562. Точки отчёта оставлены на исходных координатах. Метки связаны с соответствующими по адресу OSM-контурами через идентификаторы объектов из `demo-data.json`.
- Раскраска использует явные теги контура `building:use` и `building`. Первый описывает указанное использование, второй может отражать тип постройки. «Смешанное» ставится только по явной отметке или сочетанию жилого и коммерческого использования в одном теге. В этом срезе таких контуров не нашли. При недостаточных данных показывается «Неизвестно». [Правила тегирования OSM](https://wiki.openstreetmap.org/wiki/Key:building:use)
- В карточке площадь контура относится к геометрии на плане. Для площадей нежилых и коммерческих помещений в этой версии показывается «Нет данных». Подходящего подтверждённого источника по отдельным зданиям нет. Назначение и площади не входят в индекс v2. Мясницкая проверяется как участок карты. Демо-отчёт подключён для Митино.

## Локальная сверка GeoPackage

Исходник `D:\HSE\ГИП\map\ALL_MOSCOW.gpkg`, слой `moscow_buildings_test`, EPSG:32637. SHA-256: `DB87BE81A945D479FD2982F51A043C465BE77D74C8B83C182E30D1AC059BF516`. В 350 576 исходных записях есть крупный выброс среди сооружений, поэтому общий экстент файла для карты не используется.

Фильтр `attributes.OBJ_TYPE = Здание` оставил 285 551 запись. Аудит выявил 14 невалидных геометрий, 2 857 записей с несколькими частями и 1 720 внутренних колец. УНОМ заполнен для всех записей. 19 УНОМ повторяются по два раза. По внутренней точке контура представлены все 12 округов, 84 записи не сопоставились с `ao.geojson`. Точки A, B и C находятся в 0,0, 12,4 и 25,1 м от соответствующих контуров в GeoPackage.

Идентификатор `datasetId=60562` и поля `UNOM`, `SIMPLE_ADDRESS` указывают на адресный реестр. В метаданных GeoPackage и проекта QGIS нет ссылки на издателя геометрии или на условия распространения контуров. Проект ссылается на промежуточный `moscow_buildings_TEST.geojson`. Геометрии GeoPackage и массовая выгрузка его атрибутов остаются локальными, как и прежняя подложка `msk_basemap.gpkg`.

## Справочники для поиска

- `addresses/` - индекс адресов для поиска: адрес, точка (центр прямоугольника контура) и идентификатор OSM каждого здания с тегом `addr:housenumber` из `buildings.pmtiles`. Части по первым двум буквам названия улицы, 150 354 адреса. Собирает `tools/build_lookup.py`. Производные данные OSM, ODbL.
- `metro.json` - 275 точек станций метро и МЦК, открытых к 25.11.2026, из справочника `commercial-history` (выгружен из OSM). Используется для подписи «до метро» в карточке здания. ODbL.
- `poi/` - 101 921 объект OSM того же снимка (конкуренты 28 категорий, входы метро, остановки, офисы, якоря, вузы) в ячейках 0,02° × 0,04°. Нужны для временного расчёта карточки без внешних сервисов. Собирает `tools/build_poi.py` из PBF выше. ODbL.
